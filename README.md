

# 🏜️ Desert Treasure Hunt – 3D Unity Game

A 3D endless runner and treasure-hunting game developed using **Unity and C#**, set in an immersive desert environment. Players navigate through challenging paths, avoid obstacles, collect coins and gems, and explore the desert in search of hidden treasures.

The game combines dynamic player movement, obstacle avoidance, collectible systems, and an engaging user interface to deliver an interactive gaming experience.

---

## 🎮 Game Overview

Embark on an exciting desert adventure where your objective is to survive the journey, avoid dangerous obstacles, collect valuable treasures, and achieve the highest possible score.

Navigate through the desert using lane switching, jumping, and sliding mechanics while encountering different challenges along the way.

## ✨ Features

### 🏃 Player Movement
- Three-lane movement system (Left, Center, Right).
- Smooth lane switching.
- Jump mechanics to overcome obstacles.
- Sliding mechanics to pass under barriers.
- Keyboard and swipe-based controls.

### 🏜️ Desert Environment
- Desert-themed 3D environment.
- Sandstone structures and ancient-style ruins.
- Warm desert lighting and atmospheric fog.
- Ambient sand particle effects.
- Desert-themed obstacles and track elements.

### 💎 Collectibles and Rewards
- Coin and gem collection system.
- Treasure chest interactions.
- Score tracking and reward collection.

### ⚠️ Gameplay Mechanics
- Obstacle detection and collision handling.
- Player health and damage system.
- Game-over detection.
- Increasing gameplay challenge through movement and speed.
- Restart and Main Menu functionality.

### 🔊 User Interface and Audio
- Main Menu interface.
- Gameplay HUD.
- Score and health display.
- Game Over screen.
- Sound effects for player actions and interactions.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Unity Hub
- Compatible Unity Editor version
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Desert-Treasure-Hunt.git
```

**2. Open Unity Hub**

- Launch Unity Hub.
- Select **Add Project**.
- Choose the cloned project directory.

**3. Open the project**

- Open the project using a compatible Unity Editor version.
- Allow Unity to import and generate the required project files.

**4. Run the game**

- Open the `MainMenu` scene from the Scenes folder.
- Press the Play button in the Unity Editor.
- Start your desert treasure-hunting adventure!

## 🎯 Controls

| Action | Keyboard |
